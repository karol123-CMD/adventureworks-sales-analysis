# Ativos de UX/UI

Este diretório reúne o sistema visual final e os protótipos estruturais do dashboard AdventureWorks.

## Identidade final

- [`paleta_adventureworks_dark.md`](paleta_adventureworks_dark.md): tokens e regras semânticas;
- [`paleta_adventureworks_dark.svg`](paleta_adventureworks_dark.svg): prancha visual dos tokens;
- [`tema_adventureworks_dark.json`](tema_adventureworks_dark.json): tema-base escuro para Power BI;
- [`wireframes/`](wireframes/): cinco protótipos de estrutura e hierarquia.

O tema JSON usa somente propriedades observadas no tema incorporado ao PBIX e no tema-base local. A aparência final do relatório também depende de formatações específicas aplicadas aos visuais; portanto, importar o JSON isoladamente não reproduz todos os overrides do PBIX.

## Wireframes x capturas

Os wireframes são protótipos sem dados, usados para orientar composição, espaçamento e hierarquia. Eles não são capturas do Power BI e não devem ser apresentados como evidência de execução.

As capturas finais, preenchidas e identificadas por página, estão em [`../screenshots/`](../screenshots/).
